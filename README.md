# Ударения для озвучки

Приложение для подготовки русского текста к озвучке в ElevenLabs: расставляет ударения и ё, режет текст на части до 10 000 символов (по аятам, абзацам и строкам), позволяет разбирать слова по одному и хранит ваш словарь исправлений.

Версия: **1.4.0**

## Что нового

- **1.4.0:** двойное нажатие на слово в готовом тексте открывает выбор ударной буквы; выбор сразу сохраняется в словаре (есть кнопка «Отменить»).
- **1.3.0:** словарь спрятан в раскрывающийся «блокнот»: его можно править текстом, скачать файлом, загрузить из файла.
- **1.2.1:** скорость чтения до 2x.
- **1.2.0:** плеер с полосой воспроизведения (можно перематывать по предложениям), исправлена пауза.
- **1.1.2:** в блоке «Прослушивание» показано, сколько голосов видит браузер, и есть кнопка обновления списка.
- **1.1.1:** лучше находит русский голос и подсказывает, как его установить.
- **1.1.0:** кнопка 🔊 для прослушивания частей и слов, проверка, понимает ли голос телефона ударения.
- **1.0.0:** первая версия приложения.

## Как выложить на GitHub Pages (один раз)

1. Создайте репозиторий на github.com (например, `udareniya`), публичный.
2. **Add file → Upload files**, выберите все файлы из этой папки (index.html, sw.js, manifest.webmanifest, четыре png, README.md) и нажмите **Commit changes**. Все файлы лежат в корне репозитория, папок не нужно.
3. **Settings → Pages**: в разделе *Build and deployment* выберите *Deploy from a branch*, ветку `main`, папку `/ (root)`, сохраните.
4. Через минуту-две приложение откроется по адресу `https://ВАШ-ЛОГИН.github.io/udareniya/`.

## Как установить как приложение

- **Android (Chrome):** откройте ссылку, меню ⋮ → *Установить приложение* (или *Добавить на главный экран*).
- **iPhone (Safari):** откройте ссылку, кнопка «Поделиться» → *На экран «Домой»*.

## Как включить бесплатный режим

В «Настройках» выберите «Бесплатный словарь». При первом запуске приложение скачает словарь ударений (около 90 МБ) и сохранит его на устройстве. Дальше интернет нужен только для самого приложения. Словарь не удаляется при обновлениях.

## Как обновлять

Новые версии ставятся поверх старой, удалять приложение не нужно. Ваш словарь исправлений, настройки и текст сохраняются.

1. Загрузите на GitHub новые файлы с теми же именами (**Add file → Upload files**, GitHub заменит старые) и нажмите *Commit changes*.
2. Откройте приложение. Внизу появится «Доступна новая версия», нажмите «Обновить». Номер версии виден внизу страницы.
3. Если баннера нет, закройте приложение полностью и откройте снова: GitHub Pages обновляется с задержкой в несколько минут.

Номер версии задаётся в двух местах: `const VERSION` в `sw.js` и `const APP_VERSION` в `index.html`. Следующая версия получит номер выше (1.0.1, 1.1.0 и так далее).

Все прежние версии остаются в истории репозитория (вкладка *Commits*), так что к любой можно вернуться.

## Ключ API (по желанию)

Автоматическая расстановка через Claude работает только с вашим ключом Anthropic API (поле в «Настройках»). Ключ хранится в браузере вашего устройства.
